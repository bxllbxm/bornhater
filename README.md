# BORN HATER

싫어하는 문장을 입력하고 카메라 손동작으로 변형하는 웹사이트입니다. 현재 사이트 버전은 **38**입니다.

공개 사이트: https://bornhater.dothome.co.kr/

## 사용 방법

인트로의 사진을 클릭하고 상단 `i hate` 옆에 문장을 쓴 뒤 Enter를 누릅니다. 브라우저의 카메라 접근을 허용하면 손 추적을 사용할 수 있습니다. 카메라는 문장 입력이나 음악 버튼과 관계없이 계속 실행됩니다.

| 손동작 | 효과 |
| --- | --- |
| 가운데 손가락 | 텍스트·픽셀 파편 폭발 |
| 주먹 쥐기 | 작은 균열 |
| 주먹을 앞으로 내밀기 | 누적 파괴, 5회 펀치 후 완전히 깨짐 |
| 양손 하트 | 파란 배경·흰 발광·글리터 폭발 |
| 엄지 올리기 | 초록색 물감처럼 녹아내림 |
| 엄지 내리기 | 밈 배경과 대각선 텍스트 비 |
| 손바닥 펼치기 | 중앙 텍스트·파편을 숨기고 첨부 MP4 재생 |

손바닥 영상 중에는 BGM을 자동 음소거합니다. 다른 효과나 새 문장으로 돌아오면 이전 음악 설정을 복원합니다. 우측 하단 play/mute는 평소 BGM만 제어하며 효과음과 카메라는 계속 동작합니다. 브라우저가 소리 있는 영상 자동재생을 막으면 영상의 재생 버튼을 누릅니다.

## 로컬 실행

별도 설치나 빌드, TouchDesigner 없이 실행합니다. 저장소 루트에서:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 http://localhost:8000/ 을 엽니다. 공개 배포에서는 HTTPS가 필요합니다. MediaPipe SDK·WASM·모델을 같은 사이트에서 제공하며 첫 손 추적 준비에는 약 21 MB 다운로드가 필요합니다. 카메라 영상과 관절 좌표는 브라우저 안에서만 처리하며 서버로 보내지 않습니다. 마이크를 요청하지 않습니다.

## 검증

Node.js와 Python이 설치된 환경에서:

```sh
node --test tests/*.cjs
python3 -m unittest discover -s tests -p 'test_*.py'
```

현재 JavaScript 140개와 Python 8개 테스트가 통과합니다. 손바닥 영상 전환은 사용자도 실제 동작을 확인했습니다. 기기·조명에 따른 손 포즈 정확도는 달라질 수 있습니다.

## 배포와 파일

정적 웹 파일(`index.html`, JS/CSS, `assets/`, `vendor/`)을 웹 루트에 올립니다. 현재 Apache 설정은 `.htaccess`에 있습니다. `tests/`, `docs/`, `td/`는 웹 루트에 배포하지 않습니다.

- `assets/`: 이미지, BGM/SFX, MP4, 제스처 모델 및 제작 메모
- `vendor/mediapipe/`: 고정 버전 SDK/WASM, 라이선스와 무결성 manifest
- `tests/`: 제스처·카메라 수명 주기·효과·음악·영상 회귀 검사
- `td/`: 이전 TouchDesigner 연동 Python 소스. 현재 공유 사이트 실행에는 불필요합니다.
- `docs/development-history.md`: 작업 과정과 이전 설계 기록

개인 카메라 캡처와 손 좌표 진단, FTP 비밀번호, 원본 업로드 중복본, 배포 백업은 제외했습니다. 172–344 MB 크기의 TouchDesigner `.toe`/`.tox` 파일은 로컬에 보관되어 있으며 GitHub 일반 파일 업로드 제한으로 저장소에 포함하지 않습니다. 기존 로컬 자료는 삭제하지 않았습니다.

MediaPipe 라이선스는 `vendor/mediapipe/LICENSE`에 있습니다. 사용자 제공 음악·영상·밈 이미지에는 별도 사용권이 적용될 수 있으며, 이 저장소는 해당 자료의 재사용 허락을 부여하지 않습니다.
