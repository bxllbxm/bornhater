# 픽셀 폭발 배경

사용자가 정지 이미지 대신 레퍼런스 기반 픽셀 파편 모션을 선택했다. 외부 이미지 파일 없이 코드로 그린다.

가운데 손가락의 explode 이벤트에서 전체 화면 배경이 어두워지고 불꽃 색 사각 픽셀이 중앙에서 방사형으로 퍼지며 일부는 세로 불기둥 방향으로 올라간다. 파편은 중력에 따라 내려가며 4.6초 동안 사라진다. 어두운 배경은 HATE를 다시 누를 때 기본 색으로 초기화된다. HATE/정지/페이지 종료는 진행 중인 배경 애니메이션을 취소한다. 애니메이션 감소 설정에서는 정적인 픽셀 이미지를 표시한다.

공개 버전 14에는 원본 이미지 경로나 사전 로딩이 필요 없다. TouchDesigner 서버와 제스처 판정은 그대로 사용한다.
